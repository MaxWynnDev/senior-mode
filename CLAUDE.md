## Claude Code specifics for this repo

- This repo is the kit, so its own `.claude/` wiring is not generated by
  `install.sh` (that would be circular). If you install senior-mode into a
  scratch repo to test something, do it under `/tmp`, never here.
- The harness (`bash core/hooks/test-checklist.sh`) takes about three
  minutes on Windows Git Bash because of process spawn cost. Run it in the
  background rather than blocking a turn on it.
- `install.sh --agent all` takes about two minutes on Windows for the same
  reason. Use `--agent claude,cursor` when you are testing one adapter.
- The Bash tool cannot parse a heredoc longer than roughly 150 lines. Write
  a script file and run it instead of inlining a long Python heredoc.
- When you change anything under `core/` or `adapters/`, the generated
  output in a test target is stale until you re-run `install.sh`. Do not
  debug generated files; fix the source and regenerate.
