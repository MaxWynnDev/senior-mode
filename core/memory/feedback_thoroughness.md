metadata:

User strongly prefers comprehensive, all-at-once execution over
incremental steps. When asked to audit or fix, do everything in one pass.
Don't ask for permission on individual items, just do them all.

**How to apply:** when the directive is "fix everything", "tackle
everything", "make it super clean", treat it as authorization to handle
the full set in one coordinated pass and report results after, not to
check in item by item. Pair this with [[feedback-senior-engineer-default]]:
comprehensive still has to clear the senior bar, not just the "completed"
bar.

Related: [[feedback-no-approval-loops]].
